Kebijakan Privasi Kasir UMKM

Tanggal berlaku: 29 Oktober 2026

Dokumen ini menjelaskan bagaimana aplikasi Kasir UMKM untuk Android dan Windows ("Aplikasi") serta layanan sinkronisasi dan back-office web Kasir UMKM ("Layanan Server") menangani data. Aplikasi dipakai pemilik toko dan stafnya untuk berjualan, mengelola stok, dan mencatat piutang pelanggan.

1. Pengelola

  • Nama pengelola: Putra
  • Email kontak: itman9975@gmail.com

2. Dua cara pemakaian

  1. Mode lokal (bawaan). Semua data hanya tersimpan di perangkat. Tidak ada data toko yang dikirim ke pengelola. Aplikasi hanya sesekali (paling sering dua kali sehari, bila ada internet) mengambil daftar paket, harga, dan kontak WhatsApp pengelola dari Layanan Server; permintaan itu tidak membawa data toko apa pun, hanya informasi teknis standar (alamat IP dan jenis aplikasi) yang tidak disimpan bersama identitas toko.
  2. Tersambung ke server (opsional). Pemilik toko dapat menyambungkan perangkat ke Layanan Server agar beberapa HP/komputer dan beberapa cabang memakai data yang sama, serta untuk membuka back-office web. Sejak tersambung, data toko yang tercantum di bagian 3 dikirim ke Layanan Server yang dikelola pengelola. Sambungan dapat diputus kapan saja oleh pemilik dari Pengaturan.

3. Data yang disimpan

Data dimasukkan sendiri oleh pemilik toko dan stafnya:

  • Toko dan cabang: nama, alamat, nomor telepon, pesan struk, tarif pajak.
  • Pengguna (pemilik, supervisor, kasir): nama, peran, dan PIN dalam bentuk hash (PIN asli tidak disimpan). Untuk menyambungkan perangkat atau masuk ke back-office web, pemilik memakai email dan kata sandi (kata sandi disimpan sebagai hash di server).
  • Produk dan stok: nama, SKU, barcode, kategori, harga modal dan jual, stok, riwayat perubahan stok, dan transfer stok antar-cabang.
  • Transaksi: nomor struk, waktu, barang, diskon, pajak, metode pembayaran, kasir, pembatalan beserta alasannya, dan shift kas.
  • Pelanggan piutang (BON): nama, nomor telepon (opsional), catatan, batas utang, transaksi BON, dan pembayaran cicilan.
  • Log audit: catatan tindakan penting (misalnya pembatalan, perubahan harga, penyesuaian stok) beserta pelakunya.
  • Data perangkat (hanya bila tersambung): ID perangkat acak yang dibuat Aplikasi, nama perangkat yang diisi pemilik, kode terminal, dan versi Aplikasi. Aplikasi tidak membaca IMEI, nomor telepon perangkat, kontak, lokasi, atau ID iklan.

4. Penggunaan data

Data dipakai hanya untuk menjalankan fungsi Aplikasi: mencatat penjualan dan stok, menghitung kas shift dan piutang, menampilkan laporan, mencetak struk, menyinkronkan data antar-perangkat dan cabang toko yang sama, serta menjaga keamanan akun (misalnya pembatasan percobaan PIN). Data tidak dipakai untuk iklan, profil pemasaran, atau dijual.

Aplikasi tidak memakai iklan, Firebase, layanan analitik, atau pelacak pihak ketiga.

5. Izin perangkat

  • Kamera: hanya untuk memindai barcode. Gambar diproses langsung di perangkat (ML Kit di perangkat), tidak disimpan dan tidak dikirim. Aplikasi tetap berjalan tanpa izin ini.
  • Bluetooth / Perangkat sekitar: hanya untuk mencetak struk ke printer thermal Bluetooth yang sudah dipasangkan. Tidak dipakai untuk mencari lokasi.
  • Internet: untuk sinkronisasi dengan Layanan Server bila pemilik menyambungkannya, dan untuk mengambil daftar paket dan harga (tanpa data toko, lihat bagian 2).

6. Berbagi data

Pengelola tidak menjual atau membagikan data kepada pihak ketiga. Data hanya dapat dilihat oleh pengguna toko itu sendiri sesuai perannya (misalnya kasir tidak melihat harga modal), dan setiap toko terpisah dari toko lain di Layanan Server.

Layanan Server memakai penyedia infrastruktur untuk beroperasi, yaitu jaringan Cloudflare untuk akses aman dari internet dan penyimpanan cloud untuk salinan cadangan. Salinan cadangan dienkripsi sebelum dikirim sehingga penyedia penyimpanan tidak dapat membaca isinya.

Struk yang dibagikan pengguna lewat menu Bagikan dikirim ke aplikasi yang dipilih pengguna sendiri dan mengikuti kebijakan aplikasi tersebut.

7. Keamanan

  • Komunikasi dengan Layanan Server memakai HTTPS (terenkripsi).
  • PIN dan kata sandi disimpan sebagai hash; token sinkronisasi disimpan terenkripsi di perangkat.
  • Data toko dikecualikan dari cadangan otomatis Android/Google. Cadangan dibuat lewat fitur Cadangan di Aplikasi dalam berkas .kbak terenkripsi dengan kata sandi pilihan pemilik.
  • Back-office web mendukung kode autentikator (verifikasi dua langkah).

Tidak ada sistem yang sepenuhnya aman. Pemilik toko sebaiknya memakai kunci layar, PIN yang tidak mudah ditebak, dan membatasi siapa yang memegang perangkat kasir.

8. Penyimpanan dan penghapusan data

  • Di perangkat: data tersimpan sampai diubah melalui Aplikasi atau Aplikasi dihapus. Menghapus Aplikasi menghapus data lokalnya.
  • Di Layanan Server: data disimpan selama toko memakai Layanan. Pemilik dapat menonaktifkan pengguna dan produk dari Aplikasi atau back-office. Untuk menghapus seluruh data toko (termasuk akun pemilik dan staf) dari Layanan Server, pemilik mengirim permintaan dari email akun pemilik ke itman9975@gmail.com dengan judul "Hapus data toko". Data dihapus paling lambat 30 hari setelah permintaan dikonfirmasi; salinan cadangan terenkripsi ikut terhapus sesuai masa simpan cadangan (paling lama 8 minggu). Sebelum dihapus, pemilik dapat meminta ekspor data.

9. Anak-anak

Aplikasi ditujukan untuk kegiatan usaha, bukan untuk anak-anak, dan tidak dengan sengaja mengumpulkan data anak.

10. Perubahan kebijakan

Kebijakan ini diperbarui bila fitur atau cara pengolahan data berubah. Versi terbaru selalu tersedia di halaman tempat kebijakan ini dipublikasikan, dengan tanggal berlaku di bagian atas.
